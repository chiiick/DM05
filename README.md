# 05 · 자원 최적화 AI 데이터셋

2026 K-인공지능 제조데이터 분석 경진대회 ⑤번 과제와 CSE304 Data Mining Project Track 2를 위한 작업 폴더입니다.

## 목표

미래 1시간의 평균 전력사용량을 예측하고, 큰 예측오차와 전력 피크의 조건을 분석합니다. 대회 제출 전에 공식 문제의 예측 시점과 테스트 파일 형식에 맞추어 목표 시점을 확정합니다.

## 원본 데이터

원본 CSV는 `/mnt/c/Users/user/Downloads/5. 자원 최적화 AI 데이터셋/5. 자원 최적화 AI 데이터셋/okm_augumented_2021.csv`에 있습니다. 이 폴더에는 원본을 복사하지 않습니다.

## 확인된 데이터 문제

- 2021-01-01부터 2021-09-14까지 날짜별 24행, 총 6,168행입니다.
- 2021-07-13과 2021-07-15의 `시간` 48행은 24 이상입니다. 시각을 확실히 복구할 근거가 없어 초기 모델에서는 두 날짜를 제외합니다.
- `평균`은 같은 행의 `15분`, `30분`, `45분`, `60분` 전력에서 계산됩니다. 미래 `평균`을 예측할 때 이 네 값을 입력으로 쓰면 정답 누출입니다.
- 미래 `생산량`, `공장인원`, 실제 미래 날씨도 예측 시점에 확정돼 있지 않다면 입력할 수 없습니다. 초기 모델은 과거 관측값과 미래 시각에 미리 알 수 있는 달력 정보만 씁니다.

## 진행 순서

1. 데이터 정합성과 누락·중복·시간축 검증
2. 1시간 앞 예측 기준 모델과 개선 모델의 시간순 평가
3. 피크와 큰 오차의 조건 분석
4. 공정 일정 조정 시나리오의 가정과 한계 명시
5. KAMP 보고서·코드·발표자료, CSE304 영어 발표자료와 LLM Usage 부록 작성

수업용 최종 제출물은 생성된 코드와 분석을 직접 실행·검증하고 설명할 수 있어야 합니다. LLM 사용 도구, 대표 사용 사례, 검증 방법, 수용·수정·거절 사례를 발표 부록에 기록합니다.

## 1차 예측 실행

```bash
python3 -m pip install -r requirements.txt
python3 forecast.py \
  --data '/mnt/c/Users/user/Downloads/5. 자원 최적화 AI 데이터셋/5. 자원 최적화 AI 데이터셋/okm_augumented_2021.csv' \
  --output outputs
```

예측 시점은 **직전 시간 종료 시점**입니다. 직전 관측 전력·생산량과 과거 같은 시간의 관측, 미리 알 수 있는 달력 정보만 사용합니다. 2021년 1–6월 학습, 7월 검증, 8월–9월 14일 시험으로 나눕니다. 1시간 전력값 그대로 예측하는 지속성 기준, 1주일 전 같은 시간 기준, 릿지 회귀를 비교합니다. `outputs/summary.json`, `outputs/test_predictions.csv`, `outputs/test_first_week.png`가 생성됩니다.

첫 실행 결과와 다음 실험 방향은 [ANALYSIS.md](ANALYSIS.md)에 정리했습니다.
