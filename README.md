# 제조 전력 예측: 경진대회 ⑤ 자원 최적화

**[1-2 적응 결합](STEP_1_2.md)**: 22차 HGB AI와 1-1 상태 투영을 요청 시각까지 관측된 최근 5일 오차로 결합했습니다. 4~6월 선택 MAE는 16.264(기존 AI 17.194), 7월은 6.901입니다. 8~9월 회고 MAE는 8.540으로 기존 AI 26.425보다 낮지만 상태 투영 단독 7.641보다는 높습니다. 후자는 이미 살핀 기간이며 독립 시험 성적이 아닙니다. `python3 step_1_2.py`로 재현합니다.

**[1-1 대안 ZIP 비교·상태 적응 예측](STEP_1_1.md)**: 별도 프로젝트의 예측식을 같은 4,224개 지정 구간 요청으로 재현했습니다. 8~9월 회고 MAE는 7.641로 기존 22차 AI의 26.425보다 낮지만, 사전 선택 구간 4~6월에서는 기존 모델보다 나쁩니다. 따라서 현재는 검증된 최종 모델이 아닌 연구 후보입니다. `python3 step_1_1.py`로 평가하고 `--origin/--start/--end`로 지정 구간을 예측합니다.

제6회 K-인공지능 제조데이터 분석 경진대회 ⑤번 과제의 **22차까지의 실험·추론 코드**입니다. 원문의 ‘향후 지정된 시간구간’에 맞춰 **예측 요청 시점과 미래 시작·종료 시각을 받는 기능**을 추가했습니다. 현재 검증된 요청 범위는 1~24시간 선행의 정각 단위 구간이며 공식 구간은 아직 확인되지 않았습니다. 기존 다음 1시간 모델과 자정 24시간 모델도 비교·감시용으로 유지합니다. 전력 단위와 계약 최대수요 정의는 미확정입니다.

## 최종 결과

2021년 8월 1일~9월 14일 1,080시간을 월초 재학습으로 평가했습니다. 개발 중 여러 번 확인한 기간이므로 **독립 시험 성적이 아닌 회고적 실험 결과**입니다.

| 항목 | 이전 결과 | 최종 결과 |
|---|---:|---:|
| 평균 절대오차 MAE | 5차 5.067 | **4.904** |
| RMSE | 5차 8.879 | **8.526** |
| WAPE | 5차 5.77% | **5.59%** |
| 90% 경험적 예측 범위 평균 폭 | 전체 보정 28.36 | **상태별 보정 23.40** |
| 해당 범위의 실제 포함률 | 92.22% | **92.87%** |

평균 모델은 과거 15분 전력·가동 이력을 포함한 ExtraTrees와 저부하 지속성 규칙입니다. MAE는 5차보다 3.2% 낮지만 개선량의 주간 블록 재표본추출 95% 구간은 **−0.069~0.411**로 0을 포함합니다. 피크 경보는 기존 정책을 유지해 **적중 116·오경보 126·미탐 7시간**입니다. 새 경보 후보들은 오경보를 줄이는 대신 미탐이 늘었습니다.

**[최종 분석 보고서](REPORT.md)** · **[15차 변경·검증](STAGE15.md)** · **[진단 그림](outputs/stage15/final_diagnostics.png)**

경진대회 ⑤번 요구와 채점 항목별 근거·한계를 모은 **[기술 보고서](COMPETITION_5_REPORT.md)**를 추가했습니다. 19~21차는 기존 모델·피크 경보를 재선택하지 않았습니다.

원문 요구·서면평가·제출물의 누락을 다시 점검한 **[경진대회 정합성 감사](COMPETITION_AUDIT.md)**도 확인하세요. 원문 제출기한은 2026년 10월 8일 23:59이며, 공식 보고서 양식·별도 테스트데이터는 현재 작업 폴더에 없습니다.

**[22차 지정 구간 예측](STAGE22.md)**은 전주·전일·직전 값 기준선과 전주 잔차를 보정하는 AI 모델을 같은 요청에서 비교합니다. 4~6월 선택에서 AI를 채택했고 8~9월 회고 MAE는 **26.425**(전주 32.136)입니다. 이 기간은 여러 번 확인한 자료이며 독립 시험이 아닙니다. 아래 1시간 MAE 4.904와는 서로 다른 예측 과업입니다.

입력 55개의 의미와 생성 시점은 **[특징 설명서](FEATURES.md)**에 정리했습니다.

16차의 전환 보정 후보는 채택 기준을 통과하지 못해 위 한 시간 구성을 유지했습니다. 17차의 하루 예측에서는 전주 기준이 선택됐으나 8~9월 MAE가 **31.521**로 컸습니다. 18차 모의 이동에서는 예측상 효과와 실제 관측에 적용한 산술적 효과가 크게 달랐습니다. [운영 조정 제안서](OPERATIONS.md)에 가정·실패·현장 확인 절차를 정리했습니다. 하루 예측과 한 시간 순차 예측은 관측 가능한 정보가 다른 과업입니다.

## 실행

Python 3.10에서 저장된 실험 결과를 사용해 최종 모델을 만들고 마지막 관측의 다음 시간을 예측합니다.

```bash
python3 -m pip install -r requirements.txt
python3 release.py train
python3 release.py predict
python3 -m unittest discover -s tests -v
```

하루 계획용 기능과 운영 시나리오는 다음 명령으로 실행합니다.

```bash
python3 transitions.py
python3 horizon.py
python3 operations.py
python3 data_contract.py
python3 condition_analysis.py
python3 decision_guard.py
python3 specified_interval.py
python3 specified_interval.py --origin '2021-09-14 23:00' --start '2021-09-15 08:00' --end '2021-09-15 14:00'
python3 step_1_1.py
python3 step_1_2.py
python3 step_1_2.py --origin '2021-09-14 23:00' --start '2021-09-15 08:00' --end '2021-09-15 14:00'
```

`horizon.py`는 모델 비교 후 하루 예측을 저장합니다. 저장된 구성으로 추론만 하려면 `python3 horizon.py --predict-only`를 사용합니다. `operations.py`의 결과는 실제 작업·생산 제약이 미확인인 가정별 모의 계획으로, 자동 실행할 운전 명령이 아닙니다.

- 모델: `artifacts/final.joblib` — Git에서 제외하며 위 명령으로 생성합니다.
- 학습·환경·입력·보정 이력: `artifacts/final.json`.
- 다음 시간 예측: `outputs/stage15/next_prediction.json`.
- 조건별 진단: `outputs/stage15/diagnostics.json`, `largest_errors.csv`, `diagnostic_predictions.csv`.
- 평균 평가 예측: `outputs/stage13/predictions.csv`; 범위 평가: `outputs/stage14/interval_predictions.csv`.
- 모델 파일은 이 저장소에서 직접 생성한 파일을 사용합니다.

학습 CSV가 실험 당시 데이터와 다르면 학습을 중단합니다. 새 데이터로 바꾸면 평가·보정 결과도 다시 생성해야 합니다. 추론 CSV는 학습 이후 관측을 추가할 수 있으며, 필요한 정확한 과거 시간값이 있어야 합니다. 예측 대상 시간의 정답은 필요하지 않습니다.

전체 실험을 순서대로 다시 실행하려면:

```bash
python3 reproduce.py --list
python3 reproduce.py
```

전체 재현은 기존 `outputs/`와 모델 파일을 갱신하며 모든 후보를 다시 학습합니다. 1~5차는 `forecast.py`에 통합돼 있습니다. `deploy.py`와 `artifacts/latest.json`은 8차의 역사적 결과이며, **현재 최종 추론 명령은 release.py**입니다.

## 평가와 데이터 처리

- 각 검증 월은 이전 시점만 학습합니다. 9차 이후 후보 선택은 4~6월 월별 MAE의 단순평균, 7월은 별도 진단입니다. 초기 실험은 4~7월 선택으로 방식이 다릅니다.
- 같은 시간의 15·30·45·60분 전력과 생산량은 정답·사후 분석에만 사용합니다. 입력은 과거 관측과 달력입니다.
- 시간 손상으로 7월 13·15일을 제외하고, 빈 시간을 유지해 지연값이 잘못 이어지지 않도록 합니다.
- 최대 169시간 과거값이 필요합니다. 필수 과거값이 없으면 예측을 거부합니다.
- 시간별 15분 최대값 **182 이상**을 임시 피크로 정의합니다. 모델의 위험 점수는 보정된 확률이 아닙니다.
- 255개 날짜에 139개 고유 일별 평균전력 모양만 존재합니다. 데이터 증강·생성 과정은 확인되지 않았습니다.
